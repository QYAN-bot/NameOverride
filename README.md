# Name Override

SillyTavern 扩展插件，用于在发送前将输入框中的 `char` / `user` 占位符一键替换为自定义名字。设置按角色卡独立记忆。

## 安装

Extensions → Install Extension → 粘贴本仓库地址

## 用法

1. Extensions 面板 → **名称替换设置** → 填写 char / user 的替换名字
2. 在聊天输入框中使用占位符（如 `{{char}}`）
3. 点击魔棒菜单 → **名称替换**
4. 输入框中的占位符被替换为设置的名字，确认后发送

留空 = 不替换该项。

## 支持的格式

插件会按以下顺序级联检测，命中第一种后停止：

| 优先级 | 格式 | 示例 |
|--------|------|------|
| 1 | `{{char}}` / `{{user}}` | 双花括号包裹（不区分大小写） |
| 2 | `<char>` / `<user>` | 尖括号包裹 |
| 3 | `char` / `user` | 纯文本（词边界匹配） |

替换完成后会弹窗提示命中了哪种格式。
